First-time setup

Connect your database

Shree Shyam Home Stay stores its data in your local PostgreSQL server. Enter the connection details for the shree_shyam database. Your password is stored only on this computer, in %APPDATA%\ShreeShyamHomeStay\config.env — never inside the installation folder and never sent anywhere else.

PostgreSQL must be installed and running on this PC. The application uses the existing shree_shyam database — no data is created, copied or deleted during setup. A strong SESSION_SECRET is generated automatically.
